# 免费模型接入

当前项目没有配置或调用真实模型，默认不会产生模型费用。真实数据查询和报告导出不依赖模型。

1. 在硅基流动官网注册并登录，查看控制台中当前标注为免费的文本模型。不要把合作应用的免费额度当成个人 API 的免费承诺。
2. 复制所选模型的完整模型 ID，并创建 API Key。不要在聊天或截图中发送完整密钥。
3. 在项目目录的终端运行 `npm run model:configure`。脚本先询问模型 ID，再要求确认账号页面显示免费，最后隐藏输入密钥。
4. 脚本仅写入本地 `.dev.vars`。这个文件已排除在 Git 和交付源码之外。重启本地预览。
5. 网站的“模型解读”按钮在配置有效时启用。部署站需单独通过 Sites 的环境设置配置模型 ID、启用开关和密钥；本地密钥不会随源码发布。

服务地址固定为 `https://api.siliconflow.cn/v1/chat/completions`。发送的内容仅含所选公开合约的统计、区块和时间范围。模型只负责解释统计，不持有钱包私钥，不发起付款；结果单独标明模型名与生成时间。

免费模型有账户限流，可能返回 429 或临时不可用。程序会显示失败，不会自动切换付费模型。收费模型一般分别按输入、输出 Token 计费；当前没有开通、充值或授权收费模型。并发缓存未命中可能调用多次，付费接入前还需要独立的用量上限。

官方资料（2026-09-24 查询）：
- [免费模型与账户限流](https://docs.siliconflow.cn/docs/userguide/faqs/rate-limit-and-upgradation)
- [Chat Completions API](https://docs.siliconflow.cn/docs/api/chat-completions-post)

免费可用型号以登录后的账号页面为准，不能保证某一型号永久免费。
